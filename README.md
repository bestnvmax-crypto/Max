# Лендинг УМК для онлайн-школы

Готовая статическая страница лендинга находится в файле `index.html`.

## Быстрый просмотр локально

### Вариант 1: открыть файл напрямую
Откройте `index.html` в браузере двойным кликом.

### Вариант 2: через локальный сервер (рекомендуется)
```bash
python3 -m http.server 8080
```
После запуска откройте в браузере:

- http://localhost:8080/

## Публикация в GitHub Pages

В репозитории добавлен workflow `.github/workflows/pages.yml`, который публикует статический сайт в GitHub Pages.

Что нужно сделать в репозитории GitHub:
1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Source: GitHub Actions**.
3. Запушьте изменения в рабочую ветку (`work`) или в `main` / `master`.
4. Дождитесь выполнения workflow **Deploy static landing to GitHub Pages**.

После успешного деплоя ссылка на сайт будет доступна в разделе **Actions** и **Settings → Pages**.

## Состав проекта

- `index.html` — структура и контент лендинга.
- `styles.css` — стили и адаптивная вёрстка.
- `script.js` — клиентская логика формы (заглушка с TODO для интеграции с backend/CRM).
